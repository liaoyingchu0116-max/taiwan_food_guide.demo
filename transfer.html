個人紀錄搬移

把熟悉的清單，帶過去。

這個頁面只在你的瀏覽器讀取檔案、產生匯入指令，不會上傳檔案，也不會自動更改線上資料庫。

必須與 Cloudflare Console 剛查到的 id 完全一致，而且帳號尚無個人紀錄。

接下來怎麼做

  1. 先確認上方顯示的帳號與筆數。
  2. 按「複製匯入指令」，回到 Cloudflare 的試用資料庫 Console。
  3. 貼到最下方輸入框，按一次 Execute。
  4. 結果應顯示 imported = 1，再核對各項筆數。

只用在目前的新試用資料庫。指令會保留受影響資料的快照、連結原有帳號，並防止重複匯入；如果發現帳號已有紀錄或原資料被改動，會拒絕搬移。指令檔也含私人紀錄，請勿放進公開專案。本工具不處理圖片、食誌或專欄；若檔案包含這些內容，會停止並請你另外規劃。
